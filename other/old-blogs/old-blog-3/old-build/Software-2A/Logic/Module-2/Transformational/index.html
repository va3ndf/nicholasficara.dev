Transformational Proofs

  • comm_assoc
    • Associativity of operations. Think P∧QP \land QP∧Q is the same as Q∧PQ \land PQ∧P
  • distr
    • Distributivity of operations. Think P∧(Q∨R)P \land (Q \lor R)P∧(Q∨R) is the same as (P∧Q)∨(P∧R)(P \land Q) \lor (P \land R)(P∧Q)∨(P∧R)
  • equiv
    • Equivalence. Think P⇔Q↔(P⇒Q)∧(Q⇒P)P ⇔ Q ↔ (P ⇒ Q) ∧ (Q ⇒ P)P⇔Q↔(P⇒Q)∧(Q⇒P)
  • dm
    • De Morgan's Law. Think ¬(P∨Q)↔¬P∧¬Q¬(P \lor Q) ↔ ¬P ∧ ¬Q¬(P∨Q)↔¬P∧¬Q
  • simp1
    • Simplification. Think about simplifying a boolean valuation, so something like P∧true↔PP ∧ true ↔ PP∧true↔P
  • simp2
    • Simplication of two (2) variables. Think P∨(P∧Q)↔PP \lor (P ∧ Q) ↔ PP∨(P∧Q)↔P
  • idemp
    • Idempotency. Think simplification of the same variable. P∨P↔PP \lor P ↔ PP∨P↔P
  • neg
    • Negation. Think ¬(¬P)↔P¬(¬P) ↔ P¬(¬P)↔P
  • contr
    • Contradiction. Think P∧¬P↔falseP ∧ ¬P ↔ falseP∧¬P↔false
  • lem
    • Law of Excluded Middle. Think P∨¬P↔trueP \lor ¬P ↔ trueP∨¬P↔true
  • impl
    • Implication. Think P⇒Q↔¬P∨QP ⇒ Q ↔ ¬P \lor QP⇒Q↔¬P∨Q
  • contrapos
    • Contrapositive. Think P⇒Q↔¬Q⇒¬PP ⇒ Q ↔ ¬Q ⇒ ¬PP⇒Q↔¬Q⇒¬P
note

When the quesetion says to check if two formulas are logically equivalent, use the <-> or ↔↔↔ symbol between the formulas.

General format:

equation_1 ↔ equation_2

↔ eqation_1
↔ modified_equation_1 by x

CNF & DNF​

  • CNF: Conjunctive Normal Form
    • A formula is in CNF if it is a conjunction of disjunctions of literals
  • DNF: Disjunctive Normal Form
    • A formula is in DNF if it is a disjunction of conjunctions of literals
  • false and true are both CNF & DNF
  • If false or true appear elsewhere in a formula, it is neither CNF nor DNF
note

A literal is a variable or its negation.

caution

A formula can be both CNF and DNF. Check for both definitions. See the quiz below.
